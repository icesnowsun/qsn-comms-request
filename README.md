# QSN Communications Request Form

Request form for the Quantitative Staff Network (QSN) Communications Subcommittee.
QSN members and subcommittees use it to request event promotion and project support.

**Live form:** https://icesnowsun.github.io/qsn-comms-request/

## How it works
- Single static page (`index.html`), hosted on GitHub Pages.
- Submissions are emailed to Admin QSN (admin.qsn@umich.edu) via [FormSubmit](https://formsubmit.co).

## Editing
Open `index.html` and edit the `CONFIG` block near the bottom:
- `recipient` – where submissions are sent
- `groups`, `needs`, `channels`, `metrics` – dropdown/checkbox options
- `minBusinessDays` – lead-time warning (default: 2 weeks)

Changes go live 1–2 minutes after committing.
